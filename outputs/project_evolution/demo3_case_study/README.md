# Demo3 Controlled Case Study

This folder contains a small curated set of reproduced diagnostic outputs on a single controlled demo3 input. The purpose is to explain the project’s pipeline evolution and design decisions using a consistent image across mask generation, mask refinement, auto/manual comparison, and final restoration output.

These artifacts are qualitative evidence, not a dataset-level benchmark.

## Stages

- 01_input_and_problem
- 02_auto_mask_or_pipeline_output
- 04_hybrid_mask_construction
- 05_final_pipeline_output
