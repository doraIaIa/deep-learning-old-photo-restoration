# Project Evolution Outputs

This folder contains a small curated set of visual outputs that document how the restoration system improved over successive development stages.

These artifacts are intentionally tracked because they explain the design decisions behind the final modular pipeline.

They are different from normal generated outputs:

* outputs/: local generated outputs, ignored by default.
* outputs/project_evolution/: curated evidence of project development, intentionally tracked.
* examples/golden/: frozen regression references.
* docs/assets/: documentation images directly embedded in README/docs.
* external experiment_value/: broader working archive for report writing and audits.
